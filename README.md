This is a simple template for a PhD thesis that complies with the guidelines of the Department of Condensed Matter Physics of the University of Zaragoza.

It builds upon previous templates from Juan José Mazo and Jesús Gómez Gardeñes. 
The main features are:
* The packages to handle the geometry, pagestyle and bibliography have been updated to more modern options.
* The config file is fully commented, claryfing the purpose of every import and setting. In particular, the comments clarify which settings are there to comply with the guidelines and which are free choices.
